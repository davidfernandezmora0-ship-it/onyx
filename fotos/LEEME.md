# Fotos

Sube aquí las imágenes con estos nombres exactos (si falta alguna, la web muestra un fondo elegante en su lugar):

| Archivo | Dónde aparece | Tamaño recomendado |
|---|---|---|
| `hero.jpg` | Portada (fondo a pantalla completa) | 1920×1280, vertical u horizontal |
| `arys.jpg` | Sección "Sobre Arys" | 1200×1500 (4:5) |
| `antes-1.jpg` … `antes-3.jpg` | Galería, foto "Antes" | 900×1200 (3:4) |
| `despues-1.jpg` … `despues-3.jpg` | Galería, foto "Después" | 900×1200 (3:4) |
| `novia.jpg` | Sección "Novias y eventos" | 1200×1500 (4:5) |

Comprime las fotos (por ejemplo con squoosh.app) para que pesen menos de 300 KB cada una.
